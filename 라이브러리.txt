======================================================================
주식 플랫폼 프로젝트(Stock Platform) 라이브러리 설치 가이드
======================================================================

본 문서는 프로젝트 개발 환경 구축 및 데이터베이스, 차트 시각화를 위해 
가상환경(venv) 및 노드 환경(npm)에 설치한 외부 라이브러리 정리 파일입니다.

----------------------------------------------------------------------
1. 백엔드 (Backend - Python / FastAPI)
----------------------------------------------------------------------
터미널에서 가상환경(venv)을 활성화한 후 아래 명령어로 개별 설치하거나,
pip freeze > requirements.txt 로 관리할 수 있습니다.

▪ fastapi
  - 역할: 현대적이고 빠른 Python 기반 웹 프레임워크. API 엔드포인트 구축용.
  - 설치: pip install fastapi

▪ uvicorn
  - 역할: FastAPI 애플리케이션을 실행하기 위한 초고속 ASGI 웹 서버.
  - 설치: pip install uvicorn

▪ sqlalchemy
  - 역할: 파이썬 코드로 데이터베이스를 다루게 해주는 핵심 ORM 라이브러리.
  - 설치: pip install sqlalchemy

▪ psycopg2 / psycopg2-binary
  - 역할: 파이썬과 PostgreSQL 데이터베이스를 연결해 주는 공식 드라이버.
  - 설치: pip install psycopg2-binary
  
▪ pydantic
  - 역할: FastAPI 입출력 데이터의 가이드라인(Schema)을 잡고 검증하는 라이브러리.
  - 설치: (fastapi 설치 시 내장되어 함께 설치됨)

[백엔드 한방 설치 치트키]
pip install fastapi uvicorn sqlalchemy psycopg2-binary


----------------------------------------------------------------------
2. 프론트엔드 (Frontend - Node.js / React)
----------------------------------------------------------------------
리액트 프로젝트 폴더 내부에서 실행하는 npm 라이브러리입니다.
설치 시 package.json 파일의 dependencies에 자동으로 등록됩니다.

▪ axios
  - 역할: 리액트 화면에서 백엔드 FastAPI 서버(http://127.0.0.1:8000)로 
          데이터를 요청하고 받아오는 HTTP 비동기 통신 라이브러리.
  - 설치: npm install axios

▪ recharts
  - 역할: 리액트 전용 반응형 차트 라이브러리. 
          백엔드에서 받은 시계열 주가 데이터를 화려한 라인 그래프로 시각화함.
  - 설치: npm install recharts

[프론트엔드 한방 설치 치트키]
npm install axios recharts

======================================================================
[참고] 개발 서버 실행 명령 루틴
======================================================================
- 백엔드 실행 (stock_platform 폴더):
  uvicorn app.main:app --reload

- 프론트엔드 실행 (react 폴더):
  npm run dev
