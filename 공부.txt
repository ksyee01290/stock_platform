가상환경 세팅
python -m venv venv

venv\Scripts\activate = 윈도우
source venv/bin/activate = 맥 또는 Linux인경우

필수 라이브러리 (fastapi, uvicorn)
pip installl fastapi uvicorn

db 라이브러리 (sqlalchemy, psycopg2-binary)
pip installl sqlalchemy psycopg2--binary

서버실행코드
uvicorn app.maini:app --reload 
--reload ==코드를 수정하고 저장할때마다 서버 재시동 옵션

api 문서페이지 (docs)
http://127.0.0.1:8000/docs
